<h1 align=center>Temporizador</h1>

> <h2>Sobre</h2>

Este projeto foi desenvolvido para praticar ReactJS, principalmente o uso de useState, useEffect e useRef, além de trabalhar com componentes e gerenciamento de estados. O projeto consiste em um sistema de temporizadores onde é possível definir um título e um tempo para criar diferentes timers, podendo iniciar e acompanhar cada um deles de forma independente.

Também utilizei Tailwind CSS para a estilização da interface e Framer Motion para adicionar animações e transições aos elementos, deixando a experiência mais dinâmica e agradável. O projeto serviu como prática para entender melhor como o React trabalha com estados, referências e efeitos, além de organizar uma aplicação em componentes reutilizáveis. Além de que também pratiquei o processo de deploy de uma aplicação React no GitHub Pages, configurando o projeto para gerar e publicar a versão de produção diretamente no GitHub.
